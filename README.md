# ユキナのミカタ

ピル（28錠・偽薬あり）の服薬記録アプリ。端末の中だけで動くWebアプリ（PWA）。
「つづけるミカタ」（2026-10-31サービス終了）の代わりとして、同じ使い方ができ、過去の記録を自由に直せる作りにしている。

## 機能
- 今日が何錠目か（実薬/偽薬）、ワンタップで「飲んだ」、取り消し、昨日の記録忘れの案内
- 錠剤シート画面（28錠）：タップで飲んだ記録をつけ外し。過去の日も自由に編集
- カレンダー：偽薬の日、生理、飲んだ印、メモ。日付タップで編集
- 残り錠数と、次のシートの準備の案内
- 受診予定日、かかりつけ医・薬局の名前と電話番号（メモとして保存。タップで電話はしない）
- ピルの設定：開始日（過去もOK・複数登録OK）と、飲み方（実薬・偽薬・休薬の日数）をシートごとに登録。種類が変わったら、変わった日を新しい開始日として追加するだけで、以前の記録はそのまま残る。28錠（21+7、24+4）、21錠＋休薬7、連続服用、休薬期間、自由入力に対応
- データの書き出し／読み込み（JSON）

## 公開と使い方（iPhone）
1. このフォルダをHTTPSで公開する（GitHub Pagesなど）。
2. Safariで開き、共有→「ホーム画面に追加」。**ホーム画面に追加してから**記録を始める（Safariとホーム画面アプリでは保存場所が別）。
3. 設定でシートの開始日を入れる。

## 開発メモ
- ロジックのテスト：`/System/Library/Frameworks/JavaScriptCore.framework/Versions/Current/Helpers/jsc logic.js test.js`（`ok` と出れば成功）
- 動作確認：`python3 -m http.server 8000` をこのフォルダで実行し、http://localhost:8000 を開く
- 予測や案内は目安。飲み忘れの対応など医療上の判断は、医師・薬剤師に相談する前提で、アプリには書かない
